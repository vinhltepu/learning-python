Javascript : nó là một ngôn ngữ lập trình phía sau trình duyệt (client-side) nó sẽ có các thao tác trên DOM - DOM : Document Object Model . tức là Javascript nó sẽ tương tác với các phần tử trên trang web như là : thẻ , class , id , thuộc tính của thẻ đó - nó sẽ giúp cho trang web trở nên sinh động hơn , có thể tạo ra các hiệu ứng , tương tác với người dùng - nó có thể làm việc với các API để lấy dữ liệu từ server và hiển thị lên trang web mà không cần phải tải lại trang (AJAX) - nó cũng có thể được sử dụng để phát triển các ứng dụng di động và máy tính để bàn thông qua các framework như React Native và Electron - nó là một ngôn ngữ lập trình rất phổ biến và được sử dụng rộng rãi trên toàn thế giới
