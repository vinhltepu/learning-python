# tìm hiểu về flask 

- Giới thiệu về phát triển Web với Flask
Flask là một framework web nhẹ và linh hoạt cho Python. Nó được thiết kế để giúp việc bắt đầu phát triển web trở nên nhanh chóng và dễ dàng, đồng thời vẫn đủ mạnh để xây dựng các ứng dụng web phức tạp.

- Flask là gì?
Flask là một API của Python cho phép chúng ta xây dựng các ứng dụng web. Nó được phát triển bởi Armin Ronacher.
Framework của Flask rõ ràng hơn framework của Django và cũng dễ học hơn vì có ít mã cơ bản hơn để triển khai một ứng dụng web đơn giản. Flask Python dựa trên công cụ WSGI (Web Server Gateway Interface) và công cụ mẫu Jinja2.

- Ưu điểm của Flask:
+ Flask là một framework backend nhẹ với ít phụ thuộc.
+ Flask dễ học vì API đơn giản và trực quan, giúp người mới bắt đầu dễ dàng học và sử dụng.
+ Flask là một framework linh hoạt vì nó cho phép bạn tùy chỉnh và mở rộng framework một cách dễ dàng để phù hợp với nhu cầu của bạn.
+ Flask có thể sử dụng với bất kỳ cơ sở dữ liệu nào như SQL và NoSQL và với bất kỳ công nghệ Frontend nào như React, Angular.
+ Flask tuyệt vời cho các dự án nhỏ và vừa mà không yêu cầu độ phức tạp của một framework lớn.
